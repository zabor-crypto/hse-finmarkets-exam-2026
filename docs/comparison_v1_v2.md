# V1 → V2

| Возможность | V1 | V2 |
|---|---|---|
| Банк | 200, четыре варианта | 350, семь вариантов, 25 MC и 25 открытых в каждом |
| Объяснение | Краткий текст | Эталон, простое объяснение, все пять обоснований MC либо критерии открытого ответа, точный источник |
| Пропуск | Нет | Без оценки и раскрытия; отдельный статус и возврат |
| Навигация | Последовательно после отправки | Любое из 50 заданий без отправки предыдущего |
| Черновик | Не сохранялся отдельно | Отдельные черновики текста и выбора |
| Итог | Промежуточная сумма раскрывалась | Только после 50 отправленных ответов; в аналитике незавершённого варианта только прогресс |
| Хранение | `hse.finmarkets.200.v1` | Новый ключ `hse.finmarkets.350.v2`, старый не удаляется |
| Старые ответы | 200 исходных заданий | 197 совместимых заданий, три отдельно разрешённые замены с сохранением старых ответов в истории |
| Экспорт | Ответы текущего банка | schemaVersion 2, все 350 записей банка, ответы, черновики, пропуски, история, архив V1 |
| Перезапуск | Удаление текущего прогресса варианта | Снимок в истории, изоляция остальных вариантов |
| Скачивание | ZIP 200 | Новый ZIP 350 и прежний исторический ZIP 200 |

Старые результаты не пересчитываются по новым объяснениям. Полностью пройденная V1 после обновления имеет 197 текущих ответов и три архивных ответа; обновлённые задания требуется пройти заново. Историческая запись V1 остаётся нетронутой. При отказе записи из-за квоты подготовленное состояние сохраняется в памяти с предупреждением; повреждённые байты не перезаписываются.

Исходная точка восстановления доступна по baseline commit и историческому ZIP. Локальный Git bundle дополнительно сохранён в приватном evidence. Развёртывание — прежний GitHub Pages из корня main, без backend и внешних runtime API.
